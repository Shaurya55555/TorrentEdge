Project Showcase

TorrentEdge

A distributed BitTorrent client built with Node.js, Kafka, and Nginx.

This is a documentation/showcase page for the project — it does not run a live instance of the client (the app depends on Kafka, Nginx, and Dockerized backend services). For the full source and setup instructions, see the GitHub repository.

Overview

TorrentEdge is a scalable, distributed BitTorrent client that combines peer-to-peer torrenting logic with real-time event streaming. Kafka decouples the core torrenting engine from the API and WebSocket layers, while Nginx handles reverse-proxying for static content, API requests, and WebSocket connections.

Key Features

  • Peer-to-peer torrent download/upload management
  • Real-time progress updates via WebSocket + Kafka
  • Event-driven architecture decoupling torrenting logic from the API layer
  • Nginx reverse proxy for static content, APIs, and WebSocket traffic
  • Fully Dockerized service composition (Node.js, Kafka, Nginx)
  • React-based dashboard for torrent status and progress

Tech Stack

Node.js Express Apache Kafka WebSocket (ws) Nginx MongoDB / Mongoose React Docker & Docker Compose
